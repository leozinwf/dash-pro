O **DashPro** é o seu centro de comando definitivo. Um painel de controle criado para centralizar a gestão de projetos de software, monitorando em tempo real o código-fonte, a infraestrutura e o banco de dados.

## ✨ Funcionalidades

- **Monitoramento do GitHub:** Acompanhe *stars* e *issues* abertas diretamente no painel.
- **Saúde do Banco de Dados:** Verifique em tempo real o status dos seus projetos no Supabase (Online, Pausado, Restaurando) e as taxas de sucesso das requisições ao banco.
- **Cofre de Chaves:** Armazene e visualize arquivos `.env` e `.env.local` de forma segura.
- **Acesso Rápido:** Links diretos para os ambientes de produção e painéis da Vercel e Supabase.
- **Autenticação Segura:** Sistema de login completo gerenciado pelo Supabase Auth.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** Next.js (App Router), React, Tailwind CSS, Lucide Icons.
- **Backend/Database:** Supabase (PostgreSQL, Auth, RLS).
- **Integrações:** GitHub API, Supabase Management API.
